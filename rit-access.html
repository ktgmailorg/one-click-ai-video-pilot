Safety boundary

Automatic access is deliberately narrow.

01

Only Google-verified @g.rit.edu or @rit.edu identities in RIT's Workspace qualify.

02

The invited GitHub account must authorize itself; users cannot type someone else's username.

03

Automatic access is read-only. Push, administration, and RIT Contributors team membership require human approval.

04

OAuth tokens are used server-side for the immediate identity check and are not placed in browser storage.

05

GitHub model weights, credentials, official brand assets, and course files remain separate from repository access.

Access did not work?

Confirm you selected your RIT Google account, accepted both authorization screens, and are signed into the intended GitHub account. Organization policy may require the invitation to be approved by an administrator.
