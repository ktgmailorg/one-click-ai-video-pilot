Open source

No sign-in needed. The project is public.

The One-Click AI Video Generator is open source under the Apache 2.0 license. The previous RIT identity-verification flow is retired — anyone can download, run, and contribute to the project directly on GitHub.

Everyone Repository read access

Clone, install, and run the local studio — no account required.

Contributors Pull requests welcome
