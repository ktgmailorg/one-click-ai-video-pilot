NARRATOR: When a trap occurs, the CPU automatically switches to kernel mode and

NARRATOR: Now, examine how the OS maps the vast virtual address space of a program to

NARRATOR: Each process maintains its own page table, which acts like a detailed directory.

NARRATOR: When the program accesses a specific virtual address, the hardware consults this

table to find the corresponding physical location.

NARRATOR: If the page is not currently loaded in RAM, the kernel triggers a page fault and

loads the required data from disk.

NARRATOR: This translation happens transparently, allowing programs to use large,

contiguous address spaces without worrying about physical memory constraints.

NARRATOR: Imagine a library catalog that translates shelf locations into actual room

NARRATOR: Without this system, programs would need to manually calculate every memory

address, making development nearly impossible.

NARRATOR: The page table ensures that virtual addresses remain stable while physical memory

is dynamically managed.

NARRATOR: Virtual memory extends this translation system to guarantee strict process

isolation.

NARRATOR: Each process receives its own private address space, meaning one program

cannot accidentally or maliciously read another's data.

NARRATOR: The kernel controls which physical pages are mapped to which virtual addresses,

allowing it to enforce security boundaries.

NARRATOR: When a process terminates, the kernel simply removes its page table entries,

NARRATOR: The child receives a unique process identifier and starts executing independently.

NARRATOR: This duplication happens at the process level, not the memory level.

NARRATOR: Imagine a photocopy machine that duplicates the entire document but allows the

NARRATOR: After the fork operation completes, the parent and child processes receive

NARRATOR: This distinction allows each process to immediately determine its role and choose

NARRATOR: The parent typically continues with its original task, while the child branches

NARRATOR: When a process is created, it inherits certain resources from its parent,

NARRATOR: To improve efficiency, many systems implement copy-on-write virtual memory.

NARRATOR: Instead of duplicating all memory pages when a process forks, the kernel shares

NARRATOR: Pages are only copied when one process attempts to write to them.

NARRATOR: This approach preserves the expected process behavior while maximizing resource
